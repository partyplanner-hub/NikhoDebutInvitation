# Debut Invitation (Navy & Roses)

A responsive, mobile-friendly debut (18th birthday) invitation website.

- `index.html`: the whole invitation (hero + countdown, details, program, **18 Roses**, **18 Blue Bills**, **18 Gifts**, gallery, attire/gift guide, RSVP)
- `css/debut.css`: navy theme, colors are CSS variables at the top (`:root`)
- `js/debut.js`: countdown (edit the date), falling petals, gallery lightbox, RSVP
- `images/floral/`: navy rose garlands and dividers (SVG)
- `images/photos/`: sample illustrated pictures. Replace with real photos (keep the same file names, or update `index.html`)

Names, venue and times are sample content. To change the countdown, edit the date in `js/debut.js`.
Open `index.html` in a browser to preview. No build step is needed.
